# Como ajudar

O código do Mode 7 City não é aberto, então este repositório não recebe pull requests. A melhor ajuda é jogar e contar o que achou:

- **Achou um bug?** Abra uma [issue de bug](https://github.com/guavovic/mode-7-city/issues/new?template=bug.yml) com o passo a passo e, se puder, um print ou o save da cidade.
- **Teve uma ideia?** Abra uma [sugestão](https://github.com/guavovic/mode-7-city/issues/new?template=sugestao.yml).

Antes de abrir, dê uma olhada nas [issues abertas](https://github.com/guavovic/mode-7-city/issues) pra ver se alguém já relatou a mesma coisa. A issue fica aberta até a correção sair numa versão nova.
